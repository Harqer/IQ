# Foundational Behavioral Guidelines

These guidelines are built into the workspace and always active. No configuration needed.

## Always Active Principles

### 1. Think Before Coding
- State assumptions explicitly
- Surface tradeoffs and alternatives
- Ask when uncertain
- Don't pick interpretations silently

### 2. Simplicity First
- Minimum code to solve the problem
- No speculative features
- No over-engineering
- Would a senior engineer say this is overcomplicated?

### 3. Surgical Changes
- Touch only what you must
- Every line traces to user request
- Clean up only your own mess
- Don't improve unrelated code

### 4. Goal-Driven Execution
- Define verifiable success criteria
- Transform vague goals to specific
- Loop until verified
- No "make it work" - clear criteria required

## Automatic Enforcement

These principles are automatically enforced through:
- Real-time linting during coding
- Pre-commit validation
- Git message checks
- Continuous monitoring

No flags to set, no configuration needed. This is how Windsurf behaves by default.
